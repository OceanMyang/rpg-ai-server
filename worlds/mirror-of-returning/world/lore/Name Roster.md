# Name Roster (名录)

- **Type:** Lore — every name in this world, with the characters the player needs to see

The player is an English speaker, and pinyin alone does not distinguish four people for them. **Every name
they read carries its characters:** `Pinyin (汉字)` for people, `English name (汉字)` for everything else —
in narration, in dialogue, in roll summaries, in out-of-character answers, and in the character list at the
start of a game. Never in brackets: a link's brackets are stripped before the player sees the text, and the
characters go with them.

This file is pinned every turn, so write names from it. If a name is not here, read its file; never invent
characters for a name. When you create a new entity, add its row.
